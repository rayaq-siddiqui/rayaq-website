rml architecture

A source-linked map of rml, a machine learning library written from scratch in C++20 with Bazel: tensors, autograd, layers and optimizers, classical models, and a CPU runtime that loads open-weight decoder models and generates text.

rml's README gives it two goals. The first is to teach by implementing: every concept on the ML models reference gets a clean, readable, tested implementation. The second is to run modern LLMs fast on a laptop: load open-weight decoder-only models such as Llama 3.1 8B and Qwen3 8B by mmap, and decode within about 1.5× of llama.cpp on a 16 GB Apple Silicon Mac. There are no ML dependencies.

The two goals meet in the tensor type (docs/architecture.md). Training code is written for clarity; the decode loop calls fused kernels that are tested against the readable versions. These pages describe one commit, version {{ upstream.version }}, and mark anything rml's docs describe but its code doesn't contain yet as planned.
