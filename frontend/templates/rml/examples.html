Examples

The 32 programs under examples/: what each one trains, runs or simulates, which rml modules it is built from, which /ml-models concept it demonstrates, and the test that holds it to its claim.

In short: every example is three Bazel targets, a library with the logic, a main.cc that parses positional arguments and prints, and a GoogleTest that checks the example's headline claim (the CNN beats the MLP with fewer parameters, only the LSTM learns the adding problem, Q-learning takes the cliff edge and SARSA the safe path). Twenty-eight are teaching demos, one per /ml-models concept, from an MLP to DPO, a U-Net diffusion model and a model server; they build on autograd, nn, losses and optim, or on linalg alone for the closed-form ones. Four are tools for the runtime and the inference stack: rml-chat, rml-graph-run and the two exact-output export checks. Together they hold 156 tests.

The rule behind the layout is in rml's own guidance: examples are entry points that parse flags and print, and all the logic they call lives in a library so it can be unit-tested (architecture.md L30–31, AGENTS.md L148–149). The README's quick start lists a bazel run line for each demo (README.md L32–245), which the tables below cite.

Anatomy of an example

main.cc stays a few lines: it fills an options struct from positional arguments (for the MLP only a seed), calls one function and prints its result struct (main.cc L1–20). Every random draw goes through rml/random's Philox generator, which every example but the four tools depends on, so the same options give the same numbers, which is what lets a test assert a trained model's accuracy. All targets use the rml_cc_* macros, so the warning flags and -Werror apply to examples as to the library (see {{ link('testing', 'Build and testing') }}). The binary is named after the directory except for the tools, whose binaries are rml-chat, rml-graph-run, tiny-net and tiny-models.

The four tools

The tool examples follow the same library, binary and test split but serve the runtime rather than a lesson, and each has its own deep dive:

  • rml-chat loads a GGUF file or Hugging Face directory with its tokenizer and chat template and holds a conversation, optionally with a draft model for speculative decoding (chat.h L4–6). Its 11 tests run against the toy GGUF models in rml/llm/testdata/models. See {{ link('generation', 'Generation', '#rml-chat') }}.
  • rml-graph-run loads an exported rml-graph model, feeds it inputs, times it and compares its outputs with stored references (graph_run.h L4–5), reading the golden fixtures in //rml/graph:testdata. See {{ link('executor', 'Executing a graph') }}.
  • tiny-net and tiny-models run models that tools/make_tiny_net.py and tools/make_tiny_models.py define in PyTorch, JAX and TensorFlow and export, with weights chosen so every op is exact in f32 and the output can be compared bit for bit whatever the summation order, fusion or threading (tiny_net.h L1–8, tiny_models.h L1–10). Their exports are committed under each directory's testdata/. See {{ link('exporters', 'Exporters and the model zoo') }}.

Tests

Each teaching example's test does two things: checks its building blocks against something exact (a hand-computed value, finite differences, a closed form), then trains the example with a fixed seed and asserts the result its header promises. A few of those headline tests:

TestAsserts
BeatsTheMlpWithFewerParametersThe CNN outscores the MLP on glyphs at random positions with fewer weights.
OnlyTheLstmLearnsALongMemoryThe LSTM beats predicting the mean on the adding problem; the vanilla RNN does not.
EqualsTheConvolutionViewThe step-by-step scan equals the convolution with (1, a, a², …).
OnlyTheEncoderRecoversTheFirstHalfThe bidirectional encoder fills masked positions whose mirror lies ahead; the causal one cannot.
SkipsDenoiseBetterAtLowNoiseThe U-Net with skips beats the same network without them when the noise is small.
QLearningTakesTheCliffEdgeAndSarsaTheSafePathThe two learners' greedy paths differ as Sutton and Barto's Example 6.6 says.
EachObjectiveWinsTheMetricItOptimizesListwise (LambdaRank) wins NDCG@5 by more than 0.05; pairwise (RankNet) wins pairwise accuracy.
ConceptDriftIsSeenOnlyByAccuracyUnder a concept change the three input and score monitors raise at most two alarms each, while the accuracy monitor fires within two days of the late labels arriving.
GreedyRepliesMatchTheModelAloneSpeculative decoding with a draft gives the same greedy reply as the target alone.
MatchesTheExactOutputEvery export of every tiny model reproduces its exact expected output bit for bit.

The 156 tests are spread over the 32 test files linked in the tables above, from 2 (mlp, cnn, rnn, finetune) to 11 (rml_chat). Ten examples mark their test size = "large", all of them training demos; every one runs in CI with the rest of bazel test //... (ci.yml L37).
