How jj help works

jj help prints the long help of jj or of a subcommand, the same text as --help, or one of the user docs that are compiled into the binary.

In short: clap's own help subcommand is turned off and replaced by this command. With -k, it prints an embedded Markdown doc through the pager. Otherwise it re-parses the named commands against the CLI definition, walks down to the subcommand, and prints its long help. It never loads a repo.

The command is cmd_help. Its help text: "Print this message or the help of the given subcommand(s)" (source). It is the Help variant of the top-level Command enum (source, dispatch), which also sets disable_help_subcommand so clap doesn't add its own (source).

1. Command-line surface

ArgumentTypeDefaultMeaning
COMMAND… (positional)stringsnone"Print help for the subcommand(s)", for example jj help workspace root (source).
-k, --keyword KEYWORDone of seven namesnone"Show help for keywords instead of commands". Conflicts with COMMAND. The values are bookmarks, config, filesets, glossary, revsets, templates and tutorial (source, KEYWORDS).

HelpArgs. The top-level long help ends with a hint pointing at jj help -k (source). The global flags are on the CLI page.
