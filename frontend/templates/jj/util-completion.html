How jj util completion works

jj util completion prints a static shell-completion script generated from jj's clap command tree.

In short: it hands a copy of the CLI definition to clap_complete (or clap_complete_nushell) and writes the script to stdout. That script knows subcommands and flags only. jj's other completion mode, the "dynamic" one, doesn't use this command: the shell runs jj itself with COMPLETE set, which can also complete bookmarks, revisions, operations and files (docs).

The command is cmd_util_completion. Its help text: "Print a command-line-completion script", followed by how to load it in each shell (source). It is the Completion variant of UtilCommand (source, dispatch).

1. Command-line surface

ArgumentTypeDefaultMeaning
SHELL (positional, required)one of six namesnonebash, elvish, fish, nushell, power-shell or zsh (source, ShellCompletion).

For example source <(jj util completion bash); the dynamic equivalent is source <(COMPLETE=bash jj) (docs). The global flags are on the CLI page.
