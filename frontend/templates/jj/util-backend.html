How jj util backend works

jj util backend groups commands about the current repo's commit backend. It has one: jj util backend name.

In short: jj util backend name loads the repo without snapshotting and prints the backend's name(), the same string jj wrote to .jj/repo/store/type when the repo was created: git for the Git backend, Simple for the simple backend.

The group is UtilBackendCommand, help text "Commands relating to the backend used in the current repo". It is the Backend variant of UtilCommand (source, dispatch). Its only subcommand is cmd_util_backend_name, "Print the name of the backend used in the current repo" (source).
