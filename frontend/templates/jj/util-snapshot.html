How jj util snapshot works

jj util snapshot does the working-copy snapshot almost every command does on startup, and nothing else.

In short: it calls the same workspace loader as every other command and reports whether that changed the repo's operation. Upstream suggests it for scripts, to keep the operation that captures the user's file edits separate from the operations the script's own commands create (source).

The command is cmd_util_snapshot. Its help text: "Snapshot the working copy if needed" (source). It is the Snapshot variant of UtilCommand (source, dispatch).

1. Command-line surface

No arguments: UtilSnapshotArgs is empty (source). It doesn't print the new operation's id; upstream points scripts at jj op log --no-graph --limit 1 -T id for that (source). The global flags are on the CLI page.
