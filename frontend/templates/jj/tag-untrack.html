How jj tag untrack works

jj tag untrack unlinks remote tags from the local tag of the same name. Both keep their targets, but later fetches only update the remote record, not the local tag.

In short: it is jj bookmark untrack for tags. Selection matches jj tag track; refs on the git remote and refs that aren't tracked are skipped with a warning; each remaining ref's state is set to untracked in one transaction, recorded as untrack remote tag <symbols>.

The command is cmd_tag_untrack. Its help text: an untracked remote tag "is just a pointer to the last-fetched remote tag" (source).

5. Transaction and operation

  • Transaction: always started; nothing to untrack gives Nothing changed. (source).
  • Operation description: untrack remote tag <name@remote, …> (source).
  • Commits: none.
  • jj undo or jj tag track restores the tracking.

6. Algorithm and invariants

Selection reuses the tag helpers (source), then each ref is filtered: git remote refs are refused ("This restriction can be lifted if we want to support untracked @git tags"), untracked ones are reported, and the rest flip to untracked (source). A tag deleted locally can still be untracked; its remote entry stays as an untracked remote tag.

Invariants: no target changes, local or remote.
