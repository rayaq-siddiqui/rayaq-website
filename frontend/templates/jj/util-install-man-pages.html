How jj util install-man-pages works

jj util install-man-pages writes a man page for every jj command into <PATH>/man1.

In short: it creates the man1 directory and lets the clap_mangen crate write one page per command from the clap command tree. It loads no repo. Packagers use it: the Nix build runs it and installs the result (source).

The command is cmd_util_install_man_pages. Its help text: "Install Jujutsu's manpages to the provided path" (source). It is the InstallManPages variant of UtilCommand (source, dispatch).
