How jj util diff works

jj util diff compares two files on disk with jj's own diff renderers, outside any repository.

In short: it reads both files, wraps each as a resolved one-sided Merge, and passes them to the same show_diff_bytes the repo diff commands use for file content. Only the Git and color-words formats print anything; the summary-style formats are hidden, and an external --tool prints nothing yet.

The command is cmd_util_diff. Its help text: "Compare two files on disk" (source). It is the Diff variant of UtilCommand (source, dispatch).
