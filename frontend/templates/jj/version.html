How jj version works

jj version prints the version string that was baked into the binary when it was compiled.

In short: at build time, cli/build.rs sets JJ_VERSION to the crate version, plus the source commit's hash when it can find one. main hands that string to clap, and the command prints clap's rendering of it. Nothing is loaded and nothing is written.

The command is cmd_version, one line of work. Its help text: "Display version information" (source). It is the Version variant of the top-level Command enum (source, dispatch).

1. Command-line surface

It takes no arguments of its own: VersionArgs is empty (source). The same string is also available as clap's --version/-V flag, which upstream's test uses (test); those flags bypass the default command, like --help (source).
