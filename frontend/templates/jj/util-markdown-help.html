How jj util markdown-help works

jj util markdown-help prints the help of every jj command as one Markdown document, the source of the online CLI reference.

In short: it hands the clap command tree to the clap-markdown crate and writes the result to stdout. Upstream's own test runs it and keeps the output as a snapshot that the docs site includes, so the published CLI reference is regenerated whenever a command's help changes.

The command is cmd_util_markdown_help. Its help text: "Print the CLI help for all subcommands in Markdown" (source). It is the MarkdownHelp variant of UtilCommand (source, dispatch).
