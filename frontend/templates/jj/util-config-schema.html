How jj util config-schema works

jj util config-schema prints the JSON Schema that describes jj's TOML config, the copy compiled into the binary.

In short: cli/src/config-schema.json is embedded at compile time as CONFIG_SCHEMA, and this command writes it to stdout unchanged. It reads no config and loads no repo.

The command is cmd_util_config_schema. Its help text: "Print the JSON schema for the jj TOML config format." (source). It is the ConfigSchema variant of UtilCommand (source, dispatch).
