jj-vfs-poc architecture

A detailed, source-linked map of how jj-vfs-poc (the crate jjfsd) works inside: a read-only FUSE file system that shows a jj repository's commits and workspaces as directories, from the kernel's request down to jj-lib's store.

Upstream calls this a proof of concept, and promises no completeness, performance or API stability. These pages say plainly what it doesn't do yet. For jj's own internals (commits, trees, conflicts, the working copy), see the jj architecture reference. That reference describes its own pinned jj version, which can differ from the jj-lib {{ upstream.jj_lib_version }} this crate builds against.
